# Week 1: Regression and Cost Function

Handwritten notes from **Supervised Machine Learning: Regression and Classification** (Andrew Ng, Coursera).

## Topics covered
1. **Cost function formula**: squared error cost function, J(w,b) = (1/2m) · Σ (f(x⁽ⁱ⁾) − y⁽ⁱ⁾)²
2. **Cost function intuition**: simplified model f(x) = w·x, worked example with w = 1, 0.5, 0
3. **Visualizing the cost function**: 3D surface plot and contour plot of J(w,b)
